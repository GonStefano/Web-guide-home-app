# Introducción a HomeApp

¡Bienvenido a la guía de uso oficial de **HomeApp**!

HomeApp es una aplicación móvil diseñada para ayudarte a gestionar las tareas del hogar de forma inteligente, combinando tu lista de tareas con datos reales del precio de la electricidad y del clima para darte recomendaciones útiles sobre **cuándo conviene hacer cada cosa**.

## ¿Qué puedes hacer con HomeApp?

La app tiene **4 pantallas principales** accesibles desde la barra de navegación inferior:

| Pantalla | ¿Para qué sirve? |
|:---|:---|
| 🏠 **Inicio** | Resumen del día: clima actual, precio de la luz ahora mismo, tareas de hoy y una sugerencia inteligente. |
| 📅 **Agenda** | Calendario con todas tus tareas. Crea, consulta y elimina tareas por fecha. |
| ⚡ **Smart Home** | Selecciona una tarea del hogar, elige la hora y recibe una puntuación para saber si es buen momento para hacerla. |
| 👤 **Perfil** | Gestiona tu familia, invita miembros y cambia tu contraseña. |

## Primeros Pasos

1. **Crea una cuenta** con tu correo electrónico y una contraseña.
2. **Inicia sesión** para acceder a todas las funcionalidades.
3. Navega por las pestañas para explorar la app.

> **Nota:** HomeApp detecta automáticamente tu ubicación para obtener el clima de tu ciudad. Asegúrate de permitir el acceso a la ubicación cuando se te solicite.
